# KIMN20
Omics - Analysis of large-scale biomolecular datasets

## Course archives

Previous editions of the course material are preserved as git tags: the 2025 edition is [`KIMN20-2025`](https://github.com/ImmunTech/KIMN20/tree/KIMN20-2025). After each course year ends, tag the tree as `KIMN20-<year>`; `git checkout KIMN20-<year>` restores that edition and `git diff KIMN20-<year>..main` shows what changed since.
